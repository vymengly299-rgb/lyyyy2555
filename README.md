# STRUCT AI — Next-Gen Trade Signal & Market Structure Intelligence Platform

A high-performance institutional trading web application engineered for Smart Money Concepts (SMC), automated Market Structure breakdown, and high-winrate algorithmic trade signals.

---

## 🌟 Key Features

1. **Interactive Market Structure Canvas Terminal**
   - High-precision custom Candlestick and SMC Overlay Canvas.
   - **Break of Structure (BOS)** and **Change of Character (CHoCH)** detection.
   - **Bullish & Bearish Order Blocks (OB)** with mitigation status tracking.
   - **Fair Value Gaps (FVG)** imbalance zones.
   - **Sell-Side (SSL) & Buy-Side (BSL) Liquidity Sweep** markers.
   - Dynamic real-time micro-tick price simulator.
   - Interactive crosshair with exact OHLC, volume metrics, and price levels.

2. **Real-time AI Signal Scanner & Feed**
   - Live stream of high-probability setups across **Crypto, Forex, Indices, and Commodities**.
   - Filter by asset class, direction (Long/Short), and AI confidence score.
   - Complete execution parameters: Entry price, Stop Loss, TP1 (40% off), TP2 (35% off), TP3 (Runner).
   - "Simulate Next AI Signal" button to test real-time sound alerts and HUD notifications.

3. **StructAI Strategy Copilot (AI Market Chat)**
   - Conversational AI powered by financial pattern reasoning.
   - Natural language queries: e.g. *"Find highest R:R setup on Crypto"*, *"Scan unmitigated FVG on Gold"*, *"Show 15m BOS on BTC"*.
   - One-click "Load on Chart" actions directly from AI recommendations.

4. **Multi-Timeframe Structure Heatmap Matrix**
   - Global structural alignment across 15m, 1h, 4h, and Daily timeframes.
   - Instant institutional Risk-On / Risk-Off market breadth gauge.

5. **Prop Firm & Risk Management Position Calculator**
   - Designed for prop firm challenges (FTMO, FundedNext, Apex, Topstep).
   - Calculates exact unit size, capital exposure, and daily drawdown safety margin.
   - One-click parameter sync with the active trade signal.

6. **Verified Performance & Audited Win-Rate Ledger**
   - Audited metrics: **78.4% Win Rate**, **2.64 Profit Factor**, **1 : 2.82 Average R:R**, and **6.2% Max Drawdown**.
   - Interactive cumulative equity growth curve SVG visualization.
   - Historical closed signal ledger with R-multiples.

7. **TradingView & Automated Webhook Integrations**
   - Exportable **TradingView PineScript v5** script generator.
   - Automated Webhook JSON payload router for 3Commas, Bybit, Binance Futures, and MT4/MT5.
   - Instant Telegram VIP notification dispatch testing.

8. **Web Audio Synthesizer Alert System**
   - Browser Web Audio API alerts for bullish/bearish signal triggers.
   - Sound toggle button with persistent state.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom Dark Fintech Theme
- **Icons**: Lucide React
- **Audio**: Web Audio API Sound Synthesizer
- **Visualization**: HTML5 2D Canvas & Vector Graphics
